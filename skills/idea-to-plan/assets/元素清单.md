# 小节模板 · 元素清单（贴进策划方案里用）

> **这块管什么**：数缺口——主线段数、元素数、维度数和清点结果都归这块。"不做"的语义归 `本期不做.md`。
> **元素**＝主线里出现的名词：界面 / 数据 / 规则 / 呈现 / 流程。
> **怎么触发维度**：元素触发专用维度，**不按品类触发**——不看这是什么类型的产品，只看这个元素本身要查什么。
> **填法**：每格只许写「问过」或「⛔本期不做」，**不许空着**；下面两张表的数字必须对得上。
