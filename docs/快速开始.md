# 快速开始

> 目标：**20 分钟内**从"解压"到"看到第一份策划方案"。做不到的话，问题一定在某一步说清楚了。

---

## 第 0 步：先看你要准备什么

| 需要 | 你有吗 | 没有怎么办 |
|---|---|---|
| Windows 10/11 | | 本项目只支持 Windows |
| DSH（DeepSeek Harness 桌面端） | | 去官网装。装完打开一次，登录 |
| 一把 API 钥匙（火山方舟 ARK 就行） | | 去方舟控制台建一个，复制出来备用 |
| 20 分钟 + 一个空文件夹 | | — |

---

## 第 1 步：解压到一个**没有中文、没有空格**的路径

```text
<盘符>\wuyunshou\          ← 可以
<用户目录>\张三\桌面\无人值守\  ← 不建议（中文用户名 + 空格，未验证）
```

> **为什么**：载体 CLI 走命令行，中文/空格路径在某些环节会被码页弄乱（本项目踩过）。

---

## 第 2 步：跑一次体检（只查不改，不花钱）

打开 PowerShell，`cd` 到解压出来的目录：

```powershell
node setup.mjs
```

你会看到一串 ✅ 和 ❌。**别慌**，这一步就是要把"缺什么"照出来。

---

## 第 3 步：让它自己修

```powershell
node setup.mjs --apply
```

能修的它全修了：建配置、建数据目录、渲染角色规矩、生成桥 token、预置 opencode 要用的 ripgrep……

**它修不了的只有一类**：需要你本人做的事。这时候它会**一次说完**，不会分五次打断你。

---

## 第 4 步：给钥匙（这一步只能你来做）

打开这个文件（没有就新建）：

```text
%USERPROFILE%\.dsh\.credentials.yaml
```

按这个格式加一行（把 `<你的key>` 换成真的）：

```yaml
ARK_API_KEY: "<你的key>"
```

> **一把 ARK 就能点亮三家**：opencode / codebuddy / qwen-code 都读 `ARK_API_KEY`。
> 如果你还想用 pi 作 coder-a，再补一把 `XIAOMI_API_KEY`。

存盘，再跑一次：

```powershell
node setup.mjs
```

---

## 第 5 步：真连一次（**会花钱，但只花一点点**）

```powershell
node setup.mjs --connect --yes
```

它会对每个角色发一次"只回复 OK"的最小请求。**这一步过了，才算真的通了** ——
配置文件写对 ≠ 参数真的被接受（本项目踩过：名字在册，参数一换就报 `UNSUPPORTED_REASONING_EFFORT`）。

---

## 第 6 步：体检通过

```powershell
node doctor.mjs
```

看到 `✅ 可起飞` 就行了。

- `⚠️ 能跑但有限制` ⇒ 能开工，但某个载体/功能没就绪，看它列的那几条
- `❌ 还差 N 项` ⇒ 按它说的补，补完再跑

---

## 第 7 步：开始用

打开 DSH，把 [`开始.md`](../开始.md) 里那段粘进去，然后说一句：

> **帮我写个「批量重命名图片」的小工具，先给我策划方案。**

它会先出策划方案给你看。你点头之后，才派活去写。

---

## 出问题怎么查

| 现象 | 先看这里 |
|---|---|
| `node setup.mjs` 说缺 DSH | 你没装 DSH，或装在了非标准路径 ⇒ 手动填 `config\本机映射.json` 的「DSH根」 |
| 说"专用 node 探测不到" | 同上。DSH 自带的 node 在 `<DSH根>\resources\runtime\...`，没有也能跑（会退回系统 node） |
| `--connect` 报参数不被接受 | 载体版本和 `agents\package.json` 里钉的不一样 ⇒ 用钉住的版本 |
| 门禁说红但你看不懂 | 把 `_crew\gate\latest.log` 最后 20 行贴进 issue |
| 其它 | 先 `node doctor.mjs --json`，再看看 [`KNOWN_ISSUES.md`](../KNOWN_ISSUES.md) |

**不要贴 `.credentials.yaml`，不要贴任何密钥。**
