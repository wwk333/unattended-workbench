# 工具清单

> 包里 200 多个脚本，**你真正会手动敲的只有下面这些**。其余都是被它们内部调用的模块。
> 全都零依赖（只用 Node 内置模块），全都能 `--help` 或直接跑。

## 一、三个入口（先看这三个）

| 命令 | 干什么 |
|---|---|
| `node setup.mjs` | 装机体检。`--apply` 能修的自己修；`--connect --yes` 真连一次（花钱） |
| `node doctor.mjs` | 出院体检。三档结论：✅ 可起飞 / ⚠️ 能跑但有限制 / ❌ 还差 N 项 |
| `node uninstall.mjs` | 卸载。照安装账逐条回滚，**保留**你的配置与项目。`--dry` 先看要删什么 |

## 二、日常会用到的

| 命令 | 干什么 | 什么时候用 |
|---|---|---|
| `node _unattended\计划任务.mjs --status` | 看那个「每 5 分钟兜底」的任务在不在 | 看板/看护死了没人拉起来时 |
| `node _unattended\计划任务.mjs --install` | 建它（幂等） | 被策略拦过、后来放开了 |
| `node _unattended\查坑.mjs "报错里的两三个词"` | 查坑库（三跳的第一跳） | **遇到任何错，先跑这个** |
| `node _unattended\体检.mjs --project <项目根>` | 项目体检 | 交付前 |
| `node _unattended\门禁.mjs --project <项目根>` | 跑全量测试，机器签字 | 交付前 |
| `node _unattended\看板-终端.mjs` | 看板的终端版（零依赖、只读） | 不想开浏览器时 |
| `node _unattended\载体体检.mjs` | 量一下每个载体"上手时被灌了什么" | 怀疑载体行为不对时 |
| `node tests\跑测试.mjs` | 跑本项目的全量测试（460 条） | 改完代码 |

## 三、偶尔会用到的

| 命令 | 干什么 |
|---|---|
| `node _unattended\备份-配置存档.mjs` | 把 `config\` 与台账打一份存档 |
| `node _unattended\保留清理.mjs` | 样本长期留、信封滚动删（别让它无限长） |
| `node _unattended\知识索引.mjs` | 重算知识库索引（零 token） |
| `node _unattended\_MCP工具验收.mjs` | 验 MCP 三个工具真的挂上了（零 token、可反复跑） |
| `node _unattended\_coder-b自检.mjs` | coder-a / coder-b 双路验收（**真花额度**，任务故意很小） |
| `node _unattended\打obsidian路径护栏.mjs` | 给 `dsh-obsidian` 插件打路径护栏（没装插件会自动跳过） |

## 四、发布用（自己打发行包的人）

| 命令 | 干什么 |
|---|---|
| `node scripts\export-open.mjs --doctor` | 导出前体检：密钥/用户名/盘符/缺件，全 0 才给发 |
| `node scripts\export-open.mjs --to <目录>` | 导出可发布的那份 |
| `node scripts\打包.mjs --slim --out dist` | 打瘦包 |
| `node scripts\打包.mjs --fat --agents <载体根> --out dist` | 打胖包（**打包前后都会自动过一遍上面那个体检**） |

## 五、**不列**的

剩下的两百来个脚本是内部模块：门禁、指纹、台账、看护、审核、看板、面板、契约……
它们由上面这些命令或看护循环内部调用，你不需要单独敲。

想知道某个文件是干什么的，看它开头的注释 —— **每个文件的第一段都写了"为什么需要它"**。
