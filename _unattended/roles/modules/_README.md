# 模块边界说明（`roles\modules\`）

一份模块一个文件、**人写**、**≤400 字**。工单写 `MODULE: <名>`（命令行 `--module <名>`）时，
**只在 L3/L4 的卡**里内联到 **STABLE 段末尾**（L1/L2 的 slim 卡不塞 —— 400 字占小卡一半以上）。

## 只写模型本来不会的四样

- 这个模块**归谁**、**范围到哪**（哪些目录/文件是它的）
- **别碰哪里**，以及为什么（碰了会连带坏什么）
- 本模块**特有的坑**（换别人来做一定会踩的）
- 跨模块的**约定**（改这里必须同步改哪里）

⛔ 通用编程常识、代码风格、框架用法一律不写 —— 那是规则书的事，写进来只会让卡变胖。

## 自动带（不用写 `--module`）

**L3/L4** 的卡，如果「交付物」路径里某一段与本目录下某个文件名同名（例 `server/src/account/a.ts` ↔ `account.md`），
派活会**自动**带上那一份说明：

- **所有交付物只对得上一个模块**才带；
- 对上**多个** ⇒ **不猜**（打一行 ⚠️，卡里不带块，收据里留 `moduleGuess`）—— 要带就显式 `--module <名>`；
- 一个都对不上 / L1/L2 / 没有模块文件 ⇒ **一个字都不加**；
- `--module` 显式写了 ⇒ **以显式为准**。

## 规矩

- **文件名就是模块名**：`account.md` ⇒ `MODULE: account`（写 `--module account`）
- 超 **400 字会拒绝出卡**（不是警告）；含 `${...}` 字面也会被拒（STABLE 段禁插值）
- 写了 `MODULE` 但文件不存在 ⇒ **拒绝出卡**（不静默当没写）
- 改完跑 `node _unattended\_前缀契约自检.mjs`（起飞前 ②c 也会跑）
- 模板见 `_模板.md`；**一个模块文件都没建 = 一切照旧**
