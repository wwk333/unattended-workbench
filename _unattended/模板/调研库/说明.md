# 调研库 · 上手（3 分钟）

> **这是什么**：一个项目一个库，放在 `<项目>\文档\调研\`。**原文存在盘上，大脑只看目录行** —— 换会话、换载体、换模型都不丢。
> **不建库完全不影响任何流程**；所有脚本见到"没有库"都静默跳过。

## 一、三步建库

```powershell
# ① 建骨架（幂等；不覆盖已有文件）
node <工作台>\_unattended\调研索引.mjs --project "<项目>" --init

# ② 把原文放进对应抽屉，然后**登记**（sha256/日期/校验全由脚本写，别手抄）
#    先在 资料\ 下建一个抽屉目录，例如 资料\account\，把 a.md 放进去
node <工作台>\_unattended\登记来源.mjs --project "<项目>" --drawer account --file a.md `
     --type web --url "https://…" --title "页面标题" `
     --note "登录 loginWithToken 与刷新 refreshToken" --drawer-desc "账号登录与会话刷新"

# ③ 重跑索引（两级索引只由脚本生成，人和 AI 都不许手改）
node <工作台>\_unattended\调研索引.mjs --project "<项目>"
```

想直接看效果：`--init --demo` 会建一个 `示例` 抽屉（一份原文 ＋ 一行来源表 ＋ 索引），跑通后删掉即可。

## 二、目录长什么样

```
<项目>\文档\调研\
├── _索引.md                  ← 一级索引（一行一抽屉；大脑只读这一份）
├── 资料\<抽屉>\<原文…>       ← 只放原文，一字不改；**唯一不进 git 的目录**
├── 来源\<抽屉>.md            ← 来源表（脚本写；一行一份，含"一句话说明"）
├── 索引\<抽屉>.md            ← 二级索引（脚本写；一行一份）
└── 笔记\<抽屉>__<主题>.md    ← 转述区，每句带锚 `资料/<屉>/x.md#L12-20`
```

> ⚠️ 来源表与索引**必须在 `资料/` 之外**：`.gitignore` 的 `!` 例外对"父目录被忽略"**无效**，
> 要入库的东西放在被忽略的父目录里就永远拿不回来。

## 三、谁读什么（硬纪律）

| 谁 | 读什么 | 绝不读什么 |
|---|---|---|
| **大脑** | 一级索引（全量几十行）＋ 命中的二级行 | **原文（一篇都不进它上下文）** |
| **干活的子 agent** | 卡里附的**命中行** → 自己按路径读原文 | 整份索引 |
| **外部会话** | 随便读（它就是来抓料的） | —— |

## 四、开源前

```gitignore
文档/调研/资料/
```

只忽略**第三方原文**（版权）；来源表、索引、笔记是自产内容，**照常入库** —— 否则"库删了还能重抓"这句话是空的。

**权威顺序**：**原始 URL ＞ 资料原文 ＞ 笔记**（冲突时以更靠前者为准）。

## 五、常用命令

```powershell
node <工作台>\_unattended\查调研.mjs --project "<项目>" 登录 token     # 查（只回命中行）
node <工作台>\_unattended\查调研.mjs --project "<项目>" --miss "灰度发布" --why "库里没有"
node <工作台>\_unattended\调研索引.mjs --project "<项目>" --check      # 词可达性＋锚＋来源表三检
node <工作台>\_unattended\调研体检.mjs --project "<项目>"              # 货架体检（过期/空屉/未登记）
node <工作台>\_unattended\调研体检.mjs --project "<项目>" --task T12   # 落盘收口判定
```
